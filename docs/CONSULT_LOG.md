# AI consultation log

We used three chat assistants as critics during planning. They gave advice only. Claude (Anthropic) via Claude Code wrote and ran the code and drafted the docs; the team reviewed every output and can explain every part (same wording as CREDITS.md). All prompts contained no personal data.

| Phase | Assistant | Question | Advice we used |

ChatGPT named the IMC 2025 "Fishing for Smishing" dataset. Gemini warned that the Mishra & Soni 2022 dataset reuses UCI ham, and suggested "benign twin" false-alarm tests. |
| Originality | ChatGPT, Gemini | The organizers' sample submission ("ScamCheck") already tests 40 hand-written modern texts. | Method red team | ChatGPT, Gemini, Claude | List the most serious flaws a skeptical ML judge would find | See the section below. |
| v1 results review | Claude, Gemini, ChatGPT | We shared the v1 numbers (naive fix: 97% recall but 98% false alarms on synthetic legit texts). What is the honest headline and what should we ship? | Claude: the headline is that the missing piece is modern legitimate texts, not more scam data; ship warn-only, link-gated, plus fixed rules for code requests and wrong-number openers. Gemini: a three-tier triage (red = flag + link/phone, yellow = "ask family before replying", green), translate first, add a real ham corpus (NUS SMS Corpus). We adopted the three-tier triage (post-hoc) and evaluate it: `triage` in `results/metrics.json`. The fixed rules for code requests and wrong-number openers, translate-first, and hard-negative retraining were NOT built. |

Lead with one chart: modern scam recall vs real-legit false alarms per model. Status: exploratory probe only (`tools/real_ham_probe.py`, `tools/real_ham_fix_probe.py`, aggregates in `results/real_ham_*.json`; see docs/RESULTS_DETAIL.md, section "Exploratory"). ## Red-team findings and our responses

| # | Flaw raised | Raised by | Planned response (docs/V2_SPEC.md) and STATUS |
|---|---|---|---|
| 1 | Source confound: negatives are 2012 ham, positives are modern scams, so the fix model may learn "modern era = scam", not "scam". | Claude, ChatGPT | Source-separation AUC test. Fix variant trained with half of a frozen synthetic modern-benign set as extra negatives; the other half stays test-only. Report false alarms for every model. STATUS: shortcut AUC test and false alarms for every model DONE; training on half of the synthetic set NOT DONE (the twins stay test-only). |
| 2 | The `<URL>` token alone may do most of the work. | Claude | Rule baseline "flag any `<URL>` or `<PHONE>`". Ablation: retrain without placeholder tokens. STATUS: implemented as "link or urgency word" and "link only" rules; only a `tok_date` ablation was run. |
| 3 | Synthetic false-alarm set is small and written by us. | Claude, ChatGPT, Gemini | Freeze it before results; label it a "synthetic stress test"; report counts with Wilson 95% intervals; never claim real-world precision. Prevalence-adjusted precision at an assumed 5% scam rate is marked as an assumption. STATUS: frozen set, labels and Wilson intervals DONE; prevalence-adjusted precision NOT DONE. |
| 4 | Campaign/template leakage across the time cutoff. | Claude, ChatGPT, Gemini | Cluster near-duplicates (char n-gram TF-IDF cosine > 0.8), date each cluster by first report, split whole clusters; report removed counts. STATUS: cluster split NOT DONE; near-duplicate rates across the time split and cluster-level recall inside the 2022+ test are reported instead. |
| 5 | Half-life curve mixes time with scam-type and language mix; dates are report dates, not send dates. | Claude, ChatGPT | Time zero = held-out UCI spam recall; per-year recall with counts and per scam type; call cohorts "report-date cohorts". STATUS: DONE (no half-life curve). |
| 6 | Multilingual gap is guaranteed for an English bag-of-words model; translations are an oracle. | Claude, ChatGPT, Gemini | Paired raw vs translated evaluation on the same messages, translation labelled "oracle upper reference"; out-of-vocabulary share; char n-gram model as the multilingual candidate; native-English vs translated scams reported separately. STATUS: paired raw vs translation and char n-gram models DONE; out-of-vocabulary share NOT DONE. |
| 7 | "Fix works" may only mean "more data". | Claude | Learning curve: 100 / 500 / 2,000 modern examples added. STATUS: NOT DONE. |
| 8 | Threshold chosen on test data inflates results. | ChatGPT, Gemini | Threshold fixed on a validation split from the training period, frozen before the later-period test. STATUS: DONE (5-fold out-of-fold on training data). |
