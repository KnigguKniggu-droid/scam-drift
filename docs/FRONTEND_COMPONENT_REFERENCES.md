## Implementation direction

Use **Check a suspicious text** as the landing task. Put **Paste a text** and **Try a sample** together. Make **See how scam filters fail** the entrance to a 3D sequence about the same kind of message. Use one working example to show the checker’s warning, action, and explanation. Give the experiment its own focal object and rhythm. The same user can enter either path directly.
