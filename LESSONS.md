# Scam Drift lessons

- Keep a text-only warning separate from sender verification. Use a “Needs another check” result for messages with too little usable context. Track those results separately from detected signals in evaluation.
- Benchmark the explanation path with a maximum-length message containing distinct words. Cap the number of removal variants while scoring the entire input.
- Verify failure responses as well as accepted requests. Assert that validation errors omit submitted text and retain `Cache-Control: no-store`.
- Keep the WebGL state reversible by using scroll progress and deterministic particle ranks. Compare the same chapter in both scroll directions. Check that the chapter heading and the key visual appear together near the end of the scrub.
- Check software-rendered scene draw calls and the device pixel ratio in browser automation. Measure delivery-device frame rate separately.
- Reserve the scanner and its desktop column before JavaScript loads. Lighthouse measured a large layout shift when the grid appeared only after WebGL started.
- For a full-width sticky scene, test the chapter readout alongside the visible 3D state. Verify the user-facing checker link after a wheel gesture so an active smooth-scroll animation cannot hide an anchor regression.
- Test Back and Forward after JavaScript-driven chapter links. Verify that the URL, selected step, and rendered scene agree. Test text enlargement separately from a normal-width mobile capture. The 320 px layout fit at default size and overflowed at 200% root text.
- Check overlap as well as horizontal overflow at enlarged text sizes. A 320 px opening at 200% text measured exactly 320 px wide even when the title covered the scanner. Let the cover enter normal flow at narrow text-relative widths and trigger the scrub from the first chapter.
- Measure the added recall and false alarms from a contextual classifier against the same lexical baseline on each cohort. Verify a neural-only verdict end to end and attribute highlighted words to the rule or scorer that supplied them.
- Replay the exact reported text and the visible paste without a URL. Test both beside legitimate notices that use the same financial terms. The same portfolio request moved from RED to GREEN when the visible URL was absent.
